Module layout
-------------
- badig.py, support/badig_settings.py: only optional hooks, used only by ZX-81
  (classic quoted-string hook, preprocess/postprocess, numbered-listing flag).
- zx81/badig_zx81.py: language description, lexer/parser hooks, numbered
  listing renumbering, remx expansion, implicit LET.
- zx81/tokenizer_zx81.py: .AZX -> .p in pure Python (tokens, 5-byte floats,
  graphics/inverse escapes, \{XX} bytes, remx, 64 KB program limit).
- zx81/zx81bader.py: ZX81 Basic DignifieR (classic -> Dignified).
- zx81/tokenizer_interface.py, tools_zx81.py, emulator_interface.py: tool
  integration; EightyOne default path C:\zeddy\EightyOne.exe.
- zx81/convert-zx81.ps1, convert-zx81.sh: conversion helpers.
- zx81/VSCode Extension/ (VSIX + .vscode/tasks.json template) and
  zx81/Sublime Package/BasicDignifiedZX81/.

Features
--------
- -id zx81: .DZX -> numbered .AZX -> .p; --em_run opens EightyOne.
- Long variable names -> 26 letters from Z down; declare supported.
- [?](row,column) -> PRINT AT; LET inserted for assignments.
- \{XX} literal byte escapes in code, strings and REM; number followed
  immediately by \{7E} keeps explicit hidden bytes (Go81 p2txt listings).
- Numbered .DZX listings are renumbered (jump targets become labels);
  -ls/-lp from command line, ##BB:arguments= remtag or support/badig.ini.
  Computed jumps (GOTO 10*X) stop the conversion; use -asc to keep numbers.
- remx <line>,<count>[,<byte>]: machine code REM line, default fill "0";
  first byte at 16514 when it is the first line. Program area max 48231 bytes.
- Reports -lnr, -var, -lbr, -lex, -par work; -lbr output is read-only on ZX-81.
- ZX81 Basic DignifieR options: -tl, -ks, -cp, -fl, -fr, -ut, -rv, -vb.
